# LP 納品ワークフロー

納品は「動くものを zip するだけ」に見えて、実際は事故の温床になる（開発ドキュメントや `.DS_Store` の混入、古いビルド成果物の流用、プレースホルダ GTM のまま公開、ルート絶対パスでサブディレクトリ配置時に全崩れ等）。このスキルは納品形態の判断 → 事前チェック → パッケージング → 中身検品を固定順序で行い、「先方のサーバーに置いたら動かない・余計なものが入っていた」を根絶する。

## いつ使うか

- 制作が完了し、先方サーバーへの配置用ファイル一式を求められたとき
- 検収用・確認用の中間納品（日付スナップショット）を作るとき
- 過去の納品物を修正して再納品するとき

## 判断基準

- **納品形態は 2 択で判断する。** (1) ビルドツール（Vite 等）がある案件 → `npm run build` の `dist/` 一式を渡す。ソースファイルは含めない。(2) ビルド工程のない静的案件 → プロジェクトの複製 `<プロジェクト名>_minify/` を作って CSS / JS を minify し、日付スナップショット `<プロジェクト名>_MMDD/` を複製して `<プロジェクト名>_MMDD.zip` にする。
- **`dist/` は Git 管理外なので、納品時は必ずその場でビルドし直す。** 手元に残っている古い `dist/` の流用は禁止（最終コミットが反映されていない事故が起きる）。ビルド前に `rm -rf dist` する。
- **`vite.config.js` の `base: "./"` を納品前に必ず確認する。** 納品先は `https://example.com/special/{{PROJECT_SLUG}}/` のような任意サブディレクトリ配置が前提。相対パス出力になっていないと配置先で全アセットが 404 になる。
- **納品物に含めるのはランタイム資産のみ**: `index.html`、CSS / JS（ビルド済みまたは minify 済み）、画像、音声等。**除外するもの**: `node_modules` / `.git` / `.claude` / `.vscode` / `CLAUDE.md` / `README.md` / `DEVELOPMENT.md` / `docs/` / ブリーフ等の支給資料 / ソースマップ（`*.map`）/ `package.json` 一式（静的納品時）/ `.DS_Store`（zip に混入した実例あり。必ず機械的に除去する）。
- **再納品は上書きしない。** 日付を更新した別スナップショット（`_MMDD`）として残し、どの版を渡したかを追跡可能にする。
- **チェックはパッケージング前に通す。** 納品物を作ってから不備が見つかると作り直しになる。`references/pre-delivery-checklist.md` を先に消化する。

## 手順

1. **納品形態の判別** — `package.json` と `vite.config.js` の有無で「ビルドあり / 静的」を判定する。
2. **納品前チェック** — `references/pre-delivery-checklist.md` を上から消化する（プレースホルダ残存 / GTM / OGP / リンク疎通 / 画像圧縮 / lint / console）。head 周りの詳細検品は `lp-head-setup` スキルの検品手順を併用する。
3. **パッケージング** — ビルドありは `references/vite-handoff.md`、静的は `references/static-minify-zip.md` の手順・スクリプトを実行する。
4. **中身検品** — zip の内容一覧で開発ファイル・`.DS_Store` の混入ゼロを確認し、zip を展開した状態でローカルサーバーを立てて表示・動作を確認する（minify や相対パスで壊れていないかの最終確認）。
5. **引き渡し** — 配置先パス（サブディレクトリ）の想定と、zip の展開方法・更新差分の有無を添えて渡す。

## 検品チェックリスト

- [ ] ブラウザの console に警告・エラーがゼロ（開発サーバーではなく**納品物の状態**で確認）
- [ ] `npm run lint` がパスする（ビルドあり案件）
- [ ] OGP / canonical が実 URL になっている（プレースホルダ・ローカル URL の残存なし）
- [ ] GTM が実 ID で、head スクリプト＋ body 直後 noscript の 2 点セットで入っている
- [ ] ページ内の全リンクが疎通する（404 / リンク切れゼロ。機械チェックのコマンドはチェックリスト参照）
- [ ] 画像が圧縮済み（WebP 優先。異常に大きいファイルが残っていない）
- [ ] プレースホルダ（GTM-XXXXXXX / example.com / `{{...}}` 記法）の残存ゼロ
- [ ] 納品物に開発ファイルが混入していない（`node_modules` / `.claude` / `docs` / `CLAUDE.md` / `*.map` / `.DS_Store`）
- [ ] ソースマップが出力されていない（`dist/` 内の `*.map` ゼロ）
- [ ] zip を実際に展開し、ローカルサーバーで表示・アニメーション・リンクを確認した
- [ ] 相対パス出力になっており、サブディレクトリ配置でも動く（`base: "./"` / ルート絶対パス `/...` 参照なし）
- [ ] 再納品の場合、日付スナップショットが新しい名前で残っている（旧版を上書きしていない）
