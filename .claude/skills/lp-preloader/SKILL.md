# lp-preloader

全画面プリローダーを 4 変種のパラメータ化パターンとして導入するスキル。変種ごとの完全コードは references にあり、完了通知の契約（後続アニメとの連携）は全変種共通で references/completion-contract.md に従う。

## いつ使うか

- 初期表示で画像 / フォントのちらつき（FOUC / FOUT）を隠したいとき
- ヒーロー演出の開始タイミングを「読み込み完了後」に揃えたいとき
- 重い画像・動画を多用する LP で読み込み中の体感を整えたいとき

## 変種の判断基準

| 変種 | 見た目 | 進捗ソース | 向いている条件 | 参照 |
|---|---|---|---|---|
| a: logo-fill | SVG ロゴが下から上に塗り上がる | ヒーロー画像 + Web フォント + 経過時間（LERP 補間） | ブランドロゴ SVG がある / フォント待機したい / 演出予算中 | references/variant-logo-fill.md |
| b: percent-bar | % 数値 + 細バー | ページ内の全 img + video（`canplaythrough`） | 画像・動画が多く重い / 進捗を数値で見せたい | references/variant-percent-bar.md |
| c: fly-to-header | ロゴ塗り→ヘッダー定位置へ飛翔 | 疑似進捗（`window.load` + 最低表示時間） | ヘッダーに常設ロゴがある / 演出予算高 | references/variant-fly-to-header.md |
| d: minimal-cover | 白カバーがフェードするだけ | ヒーロー画像の `decode()` のみ | ページが軽い / 演出予算最小 / ビルドなし静的構成 | references/variant-minimal-cover.md |

### 判断の観点

- **ロゴ有無**: SVG ロゴがあれば a / c、なければ b / d
- **動画有無**: ヒーローや本文に video があるなら b（`canplaythrough` 監視込み）
- **ページ重量**: 重いほど「進捗が見える」変種（a / b）。軽いページで % 表示は逆に間延びする → d
- **演出予算**: d < b < a < c の順に実装コストと視覚的リッチさが上がる

### 全変種共通の必須要素

- **最低表示時間**: 1500ms 目安。キャッシュ済みで一瞬チラつくのを防ぎ、塗り / バー演出を見せ切る
- **タイムアウト安全網**: 3000〜5000ms で強制完了。画像 1 枚の失敗でページが開かない事故を防ぐ（`error` イベントも `load` と同様にカウントする）
- **スクロールロック**: 表示中は `body` の `overflow: hidden` + `wheel` / `touchmove` の preventDefault（iOS 対策）
- **完了通知の契約**: 完了イベント名・コールバック・発火順序を references/completion-contract.md に統一する。特に **ScrollTrigger の初期化はスクロールロック解除後**に行う（`overflow: hidden` 中に初期化すると下方トリガーの位置計算が破綻する）
- **JS 無効環境**: `@media (scripting: none)` でプリローダー自体を `display: none` にする

## 導入手順

1. 上の判断表で変種を決め、該当する references を読む
2. HTML: `<body>` 直下（GTM noscript の直後）にプリローダーの DOM を置く
3. CSS / JS を references のコードで追加。ロゴパス・色・z-index・最低表示時間・タイムアウトをプロジェクト値に合わせる
4. references/completion-contract.md に従い、完了イベント（`loading:complete` 等）を発火し、後続のヒーローアニメ・ScrollTrigger 初期化・Swiper autoplay 起動をそのイベント購読に載せ替える
5. 進捗ソースの対象セレクタ（ヒーロー画像のみ / 全画像 / 画像 + 動画）を実ページに合わせる

## 検品チェックリスト

- [ ] キャッシュ有効の 2 回目アクセスでも最低表示時間だけ表示され、チラつかない
- [ ] ネットワークを Slow 3G に絞ってもタイムアウトで必ず開く
- [ ] 画像 URL を 1 つ壊しても（404）進捗が止まらず完了する
- [ ] 表示中にホイール / スワイプしてもページが動かない。完了後は普通にスクロールできる
- [ ] 完了イベントが発火し、後続アニメが開始される（イベント購読は `{ once: true }`）
- [ ] ScrollTrigger を使うページで、下方セクションの発火位置がズレていない（ロック解除後に初期化 / `ScrollTrigger.refresh()`）
- [ ] JS 無効でプリローダーが表示されず、コンテンツが見える
- [ ] `prefers-reduced-motion` で塗り / 飛翔などの動きが過剰にならない（フェードのみに縮退可）
