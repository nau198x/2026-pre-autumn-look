# responsive-br

PC と SP で改行位置を出し分けるための、`<br>` 専用ユーティリティ。文章の折り返しをデバイスごとに最適化したいとき（PC は 1 行に収めたい／SP だけ特定位置で折りたい 等）に使う。

## 使い方

HTML では改行させたい位置に、そのデバイスでだけ効かせたい `<br>` を置く。

```html
<p>
  上質な素材と美しいシルエットで<br class="pc" />エレガンスを纏う、<br
    class="sp"
  />2026 秋コレクション。
</p>
```

- `<br class="pc">` … **PC でのみ改行**（SP では改行しない）
- `<br class="sp">` … **SP でのみ改行**（PC では改行しない）
- クラスを付けない素の `<br>` … 常に改行

## CSS（`global.css` の全体共通スタイルに置く）

セクション CSS ではなく `src/styles/global.css`（全体共通スタイル）に 1 度だけ定義する。

```css
/* ----------------------------------------------------------------
 Responsive line breaks
 <br class="pc"> … PC のみ改行 / <br class="sp"> … SP のみ改行
----------------------------------------------------------------- */
br.pc {
  display: none;
}

@media (width >= 768px) {
  br.sp {
    display: none;
  }

  br.pc {
    display: inline;
  }
}
```

- **mobile-first**: 既定（SP）で `br.sp` を表示・`br.pc` を `display:none`。768px 以上で反転する
- `display:none` にした `<br>` は改行を生まない。反対デバイスで戻すときは `display: inline`（`<br>` はレンダリングされれば改行するため `inline` で復帰する）

## 設計上の要点

- **セレクタは必ず `br.pc` / `br.sp` と型を付ける**。`.pc` / `.sp` 単独にすると、画像等のブロック出し分けユーティリティ（`display:block` で表示するもの）と `display` 値が競合する。`br` に限定することで共存できる
- **SP/PC 境界は 768px を既定**とする（`responsive.md` のタブレット境界と一致）。案件で 1024px を境界にしたい場合はメディアクエリの値だけ変更する。プロジェクト内で境界値は 1 つに統一する
- 旧方式（`max-width` メディアクエリ）は使わない。`width >=` の mobile-first で書く（`css.md` / `responsive.md` 準拠）

## アクセシビリティ

- `<br>` は装飾的な改行であり、`display:none` にしても**テキスト内容は消えない**（改行の有無が変わるだけ）。スクリーンリーダーの読み上げにも影響しない
- **改行に意味を持たせない**。`<br>` を消しても文が正しく読めること（意味の区切りは句読点や要素で表現し、`<br>` は見た目の調整のみ）

## 検品チェックリスト

- [ ] CSS は `global.css` に 1 箇所だけ（セクション CSS に重複定義しない）
- [ ] セレクタが `br.pc` / `br.sp`（型付き）になっている
- [ ] SP 幅で `br.sp` が改行し `br.pc` が改行しない／PC 幅でその逆になる
- [ ] 境界値がプロジェクトの他のブレークポイントと矛盾しない（既定 768px）
- [ ] `<br>` を全て外しても各文が意味として成立する
