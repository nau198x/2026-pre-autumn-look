# /credit-list スキル

ファッション / エディトリアル LP の「ノート風細罫クレジットリスト」を導入するスキル。罫線の色分け・左→右の描画アニメ・行 stagger フェードが一体で動く。コードは全て references/ にあり、本ファイルは判断と手順のみを扱う。

## いつ使うか

- 商品写真（look）の下・横に、商品名 / 価格 / 商品ページリンクの一覧を上品に並べたいとき
- 単なる箇条書きではなく「スクロールで罫線が描き出される」エディトリアルな見せ方をしたいとき
- 1 つのリスト内に複数グループ（LEFT / RIGHT の着用者別等）を罫線の濃淡で区切りたいとき

前提: GSAP + ScrollTrigger が導入済みであること（このスキルの核。無ければ先に追加する）。

## 変種の判断基準

| 要件 | 対応 | 参照 |
| --- | --- | --- |
| 基本の 3 点構成リスト | html.md の基本構造 + css.md + js.md をそのまま | references/html.md |
| グループ頭に小見出し（RIGHT / LEFT 等）を置きたい | Tag 行（`__tag`）を追加。JS は自動対応済み | references/html.md |
| 1 つの ul 内でグループ境界を濃線にしたい | 境界行の li に `--group-end` 修飾子 | references/html.md |
| hover の白黒反転が強すぎる | opacity 変化のみの控えめ版に差し替え | references/css.md 末尾の変種 |
| 狭い SP で 3 要素が横に収まらない | SP 縦積み / PC 横並びの変種 | references/css.md 末尾の変種 |
| 発火位置・行間隔の調整 | `start: "top 85%"`・stagger 0.4s がデフォルト。JS 冒頭の定数で調整 | references/js.md |

## 導入手順

1. references/html.md を読み、リスト構造を配置する（プレフィックス `credits` は案件のセクション名に合わせてリネーム可。CSS / JS も揃えて置換する）
2. references/css.md の CSS を配置する。デザイントークン（罫線色・イージング等）が未定義のプロジェクトでは、リファレンス内の `:root` ブロックごと持ち込む
3. references/js.md の JS を `animations.js`（または独立モジュール）に追加し、DOMContentLoaded から呼ぶ
4. 旧実装から移植する場合の注意（1 行）: 旧 `--groupEnd`（camelCase）は廃止。`--group-end`（kebab-case）が正なので、HTML・CSS の両方を揃えて置換する
5. lazy 画像が多いページでは scrolltrigger-drift-fix スキルの refresh 対策を併用する（発火位置ズレ防止）

## 検品チェックリスト

- [ ] リストが viewport の 85% ラインに入った瞬間、上端の濃線が左→右に描かれる
- [ ] 各 li の下線が上から順に stagger 間隔で描かれ、同じタイミングで NAME / PRICE / CLICK がフェードインする
- [ ] 最下段の li と `--group-end` 付き li の下線だけ濃色になっている
- [ ] Tag 行（小見出し）は薄色のまま表示され、hover で反転しない
- [ ] hover でリンク行が白黒反転する（有効化した場合。反転中も 3 テキストが読める）
- [ ] JS 無効環境・`prefers-reduced-motion: reduce` で最初から全表示される（隠れたままにならない）
- [ ] 複数の ul を縦に並べた場合、罫線が二重に見えない（見える場合は margin で離す）
- [ ] 長い商品名でレイアウトが崩れない（崩れる場合は css.md の SP 縦積み変種へ）
- [ ] コンソールに警告・エラーが出ない
