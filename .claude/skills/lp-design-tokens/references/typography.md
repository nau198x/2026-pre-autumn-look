# タイポグラフィ: フォント役割構成 + clamp() 流体タイプ

ファッション・エディトリアル系 LP の定番構成「欧文ディスプレイフォント（見出し・数字）+ 和文明朝（本文）」を、2 つの役割トークンと clamp() レシピで組む。

## フォントの役割構成（2 トークン）

```css
:root {
  /* 本文・和文: 明朝スタック（Web フォント不使用でも成立するフォールバック込み） */
  --font-primary:
    "游明朝", "YuMincho", "Hiragino Mincho ProN W3", "ヒラギノ明朝 ProN W3",
    "Hiragino Mincho ProN", serif;

  /* 見出し・英字・価格数字: 欧文ディスプレイ + 明朝フォールバック
     {{DISPLAY_FONT}} は案件のブランドフォントに差し替える */
  --font-display:
    "{{DISPLAY_FONT}}", "游明朝", "YuMincho",
    "Hiragino Mincho ProN", serif;
}

html,
body {
  font-family: var(--font-primary);
}

h1,
h2,
h3,
.price,
.credit {
  font-family: var(--font-display);
}
```

設計の要点:

- **`--font-display` のフォールバックに和文明朝を必ず入れる。** 欧文ディスプレイフォントは和文グリフを持たないため、見出しに和文が混ざった時に「英字はディスプレイ体・和文は明朝」で自然に混植される（フォールバックがゴシックだと見出しだけ書体が割れる）
- 欧文ディスプレイの読み込みは案件のフォント方針（Google Fonts / 支給 woff2 の `@font-face` / ホスティングサービス）に従う。いずれの場合も `font-display: swap` 相当の挙動と、プリローダーでのフォント待機（`document.fonts.ready`）の併用を検討する
- 役割トークンは 2 つで足りる。3 つ目（サブディスプレイ等）が必要になったら `--font-display-sub` のように役割が分かる名前にする

### サイズ以外の初期値

明朝系・欧文ディスプレイ系はデフォルトの字間が詰まって見えることが多い。見出しに `letter-spacing: 0.05em〜0.12em`、本文に `line-height: 1.8〜2.0`（和文）を初期値の目安にする。

## clamp() 流体タイプのレシピ

画面幅で大きく変わるサイズは `clamp(最小, 可変, 最大)` で 1 定義に収める。ブレークポイントごとの `font-size` 上書きを乱立させない。

```css
/* ヒーロー見出し（モバイル 30px 前後 → デスクトップ 54px 前後） */
.hero__title {
  font-size: clamp(1.9rem, 3.4vw, 3.4rem);
}

/* セクション見出し */
.section__title {
  font-size: clamp(1.4rem, 2.4vw, 2.5rem);
}

/* 商品名・クレジット */
.credit__name {
  font-size: clamp(1.1rem, 2.6vw, 1.7rem);
}

/* 価格・キャプション（本文系は可変幅を小さめに） */
.credit__price {
  font-size: clamp(1rem, 2vw, 1.4rem);
}
```

### 係数の決め方

1. モバイル実機（幅 375px 想定）で欲しいサイズ = **最小値**
2. デスクトップ（幅 1280〜1440px 想定）で欲しいサイズ = **最大値**
3. 可変部の vw 係数 ≒ `最大値(px) ÷ 14`（vw で書いた値が幅 1400px 時に最大値へ届く目安）。最小・最大で頭打ちになるため厳密でなくてよい

### 注意

- **最小値を下げすぎない。** 本文相当のテキストはモバイルで 12px（0.75rem）を下回らせない
- 可変部が vw のみ（`3.4vw` 等）だとブラウザのテキスト拡大（rem 基準）に追従しない。アクセシビリティ要件が厳しい案件は `clamp(1.9rem, 1rem + 2.6vw, 3.4rem)` のように rem + vw の複合にする
- セクション単位の幅に追従させたい場合（コンテナ幅基準のスケール）は、親に `container-type: inline-size` を指定して `vw` の代わりに `cqw` を使う。ヒーローのようにセクション幅 = 画面幅なら vw で十分
- 罫線や 1px 系のディテールは clamp() 不要。流体化するのは「見出し・価格・大きめキャプション」に絞る

## 検品チェックリスト

- [ ] 見出しに和文を混ぜた時、和文が明朝でフォールバックされる（ゴシック混植になっていない）
- [ ] `--font-display` がプレースホルダ（{{DISPLAY_FONT}}）のまま残っていない
- [ ] 幅 375 / 768 / 1280px でヒーロー見出しが意図サイズになっている（clamp の下限・上限が効いている）
- [ ] Web フォント読み込み失敗時（DevTools でブロックして確認）もレイアウトが破綻しない
